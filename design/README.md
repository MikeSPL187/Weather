# Макеты Aura (Android · Россия и СНГ)

Интерактивный холст: https://claude.ai/artifact/JPvnqrQ4SK8JjHDyr4SwmY (приватный, доступ выдаётся через Share).

Исходники артбордов лежат в `project/*.dc.html`, раскладка холста — в `project/canvas.json`. Экраны телефона — 412×915 (типичный Android).

| # | Файл | Экран | Что можно потрогать |
|---|---|---|---|
| 01 | `Main.dc.html` | Главный экран с 3D-сценой | Твик `scene`: sun / rain / night / snow; выбор часа; переходы к деталям, дождю по минутам, городам, таб-бар |
| 02 | `Nowcast.dc.html` | Дождь по минутам (2 ч) | Шкала времени, уведомление, отчёт «что за окном» |
| 03 | `Forecast.dc.html` | Прогноз на 10 дней | Раскрытие дня |
| 04 | `Details.dc.html` | Ветер, УФ, солнце, воздух, влажность, давление, луна | Единицы ветра |
| 05 | `Radar.dc.html` | 3D-карта | Слои и шкала времени |
| 06 | `Assistant.dc.html` | ИИ-ассистент | Профили активностей |
| 07 | `Widgets.dc.html` | Live Update на экране блокировки, виджеты 4×2, 2×2, 3×2, 4×1 | — |
| 08 | `Cities.dc.html` | Города РФ и СНГ | Режим «Изменить», удаление и возврат |
| 09 | `Onboarding.dc.html` | 3 шага: приветствие, геолокация, уведомления | Переход по шагам, переключатели |
| 10 | `Paywall.dc.html` | Подписка Aura+ в рублях | Выбор тарифа |
| 11 | `Settings.dc.html` | Настройки | Тема (авто / светлая / тёмная), качество 3D, единицы, уменьшение движения; твик `theme` |
| 12 | `Styleguide.dc.html` | Дизайн-система «Живая диорама» | — |

3D-объекты в макетах сделаны на CSS и служат референсом. В приложении их заменят модели glTF на Filament и AGSL-шейдеры (раздел 11.4 отчёта). Цены на экране подписки — гипотезы для A/B-теста.
