# Макеты Aura

Интерактивный холст: https://claude.ai/artifact/JPvnqrQ4SK8JjHDyr4SwmY (приватный, доступ выдаётся через Share).

Исходники артбордов лежат в `project/*.dc.html`, раскладка холста — в `project/canvas.json`.

| # | Файл | Экран | Что можно потрогать |
|---|---|---|---|
| 01 | `Main.dc.html` | Главный экран с 3D-сценой | Твик `scene`: sun / rain / night / snow; выбор часа; переходы по таб-бару, к деталям и к дождю по минутам |
| 02 | `Nowcast.dc.html` | Дождь по минутам (2 ч) | Шкала времени, переключатель уведомления, отчёт «что за окном» |
| 03 | `Forecast.dc.html` | Прогноз на 10 дней | Раскрытие дня с деталями |
| 04 | `Details.dc.html` | Ветер, УФ, солнце, воздух, влажность, давление, луна | Единицы ветра м/с / км/ч |
| 05 | `Radar.dc.html` | 3D-карта | Слои (осадки, облака, температура, ветер), шкала времени |
| 06 | `Assistant.dc.html` | ИИ-ассистент | Профили активностей, «лучшее окно» |
| 07 | `Widgets.dc.html` | Dynamic Island, Lock Screen, Live Activity, виджет «Домой» | — |
| 08 | `Styleguide.dc.html` | Дизайн-система «Живая диорама» | — |

3D-объекты в макетах сделаны на CSS (объёмные градиенты, тени, анимации) и служат референсом. В продукте их заменят модели glTF/USDZ и шейдеры (см. раздел 7 отчёта).
