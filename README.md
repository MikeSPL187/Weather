# Aura — погода с 3D-дизайном

Android · Россия и СНГ.

Мобильное погодное приложение: живая 3D-сцена, которая меняется вместе с реальной погодой, минутный прогноз осадков, советы «что надеть» и «когда выйти» и никакой рекламы.

## Материалы

- [`docs/market-research.md`](docs/market-research.md) — исследование рынка, конкуренты, боли пользователей, позиционирование, функции, монетизация, стек.
- [`design/`](design/) — исходники макетов (12 артбордов, Android 412×915) и описание экранов.
- [`prototype/scene3d.html`](prototype/scene3d.html) — живой 3D-прототип главной сцены на three.js: острова-города (Москва, Петербург, Казань, Алматы), реальное положение солнца по дате и времени города, объёмные облака, лужи и вода с настоящими отражениями, 6 типов погоды, уровни качества, счётчик FPS. Опубликован: https://claude.ai/artifact/1Q5YZuCvu9H2seuWVqfCvR

## Android-приложение (MVP)

Kotlin + Jetpack Compose, minSdk 26, targetSdk 35.

| Модуль | Что внутри |
|---|---|
| `core` | Чистый Kotlin: модели погоды, клиент Open-Meteo (прогноз на 10 дней, осадки по 15 минут, качество воздуха, поиск городов на русском), расчёт солнца (NOAA), сводка «дождь закончится через N мин», советы по правилам, без ИИ и внешних сервисов («что надеть», лучшее время для пробежки, велосипеда, прогулки и фото), сводка недели, тестовые данные. Покрыт unit-тестами |
| `app` | «Сейчас»: настоящая 3D-сцена на OpenGL ES 3.0 (тени от реального солнца, отражения в воде и лужах, облака, дождь, снег, огни окон и фонарей ночью; поворот жестом), с 2.5D-сценой на Canvas как запасным вариантом; график осадков на 2 часа; кривая температуры на 24 часа; карточки ветра, УФ, солнца, ощущаемой температуры, влажности, давления и воздуха. «Прогноз» на 10 дней со сводкой недели. «Советы». Поиск и сохранение городов. «Карта» на MapLibre: тёмная векторная подложка OpenFreeMap (вода, леса, дороги, подписи на русском, 3D-здания), радар RainViewer за 2 часа и прогноз Open-Meteo на 12 часов по сетке 25 км со слоями осадков, облаков, температуры и ветра (движущиеся штрихи), один ползунок времени, кнопка «3D» опускает камеру в город. Виджет на главный экран в трёх размерах с той же сценой, обновляется в фоне каждые 30 минут |

Сборка: `./gradlew :core:test :app:assembleDebug` (нужен Android SDK 35 и JDK 17).

Скриншот-тесты Paparazzi рендерят экраны без устройства: `./gradlew :app:recordPaparazziDebug` записывает эталоны в `app/src/test/snapshots/images/`, `:app:verifyPaparazziDebug` сверяет с ними. Готовый debug-APK собирает GitHub Actions (`.github/workflows/android.yml`), его можно скачать из артефактов запуска.

Прогноз приходит из Open-Meteo (данные CC BY 4.0, бесплатно для некоммерческого использования; для коммерческого запуска нужен платный тариф или Meteum). Без сети приложение показывает последний загруженный прогноз, а если его нет — пример данных с явной пометкой. Долгое нажатие на сцену показывает другие типы погоды. Сцену на Canvas позже заменит 3D-рендер на Filament за тем же `SceneState`.

Шрифты Manrope и Unbounded распространяются по лицензии SIL OFL 1.1 (`docs/licenses/`).

### Превью 3D-сцены без телефона

Шейдеры и геометрия общие для Android и браузера, поэтому сцену можно проверить в headless Chromium:

```
SCENE_PREVIEW=1 ./gradlew :core:test --tests '*ScenePreviewExport'   # меши, кадры и шейдеры в build/scene-preview
cd tools/scene-preview && npm install && node render.mjs              # PNG в build/scene-preview/png
```
